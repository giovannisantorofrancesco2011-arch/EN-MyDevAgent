# Catch the Stars

2D game in Python with Pygame: the player moves a basket with the arrow keys and catches the stars.

## Commands
- install: `python -m pip install -r requirements.txt`
- run: `python main.py`

## Conventions
- the whole game is in main.py: constants at the top (sizes, colors, speeds), then the main loop
- the loop always does: events → update → draw → clock.tick(FPS)
- comments and text in English
