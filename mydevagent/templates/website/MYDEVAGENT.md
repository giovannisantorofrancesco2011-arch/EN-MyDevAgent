# My website

Static website: HTML, CSS and JavaScript, no build step and no dependencies.

## Commands
- preview: `/preview` opens the site in the browser; the agent checks it on its own with the `preview` tool

## Conventions
- index.html for the structure, style.css for the look, script.js for interactivity
- the colors are the CSS variables at the top of style.css (light theme and `body.dark`)
- text in English
